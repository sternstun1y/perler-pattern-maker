# 拼豆图纸生成器（Perler Beads Pattern Maker）

一个纯前端的拼豆图纸生成工具：上传任意图片（普通照片或像素图），自动匹配
Perler 实体豆色号，生成带网格线和色号标注的拼豆图纸，并支持导出图纸 PNG
和用豆量清单 CSV。

## 功能

- **图片上传**：点击或拖拽，支持 PNG / JPG / WebP，透明像素自动留空
- **照片转像素（进阶功能）**：内置中位切分（Median Cut）降色算法，普通照片
  自动收敛为 K 色像素画后再匹配实体豆，支持 6~48 色调节
- **色盘匹配**：内置 Perler 官方 117 色（色号 P01~P961），在 CIELAB 色彩空间
  做最近邻匹配，比 RGB 距离更符合人眼感知
- **杂点清理**：孤豆自动并入四周主流色，图纸更干净、更好拼
- **图纸生成**：网格线（每 10 格加粗）+ 行列坐标 + 每格色号标注（按豆色亮度
  自动黑字/白字）
- **导出下载**：图纸高清 PNG、用豆量清单 CSV（带 BOM，WPS/Excel 直接打开不乱码）
- **用豆量清单**：每种色号需要多少颗豆，附"建议购买"列（含 10% 备损），
  按数量排序，可直接指导采购
- **图纸信息栏**：导出的图纸 PNG 底部含板型尺寸、总颗数、色数与生成日期，
  打印后自解释

## 本地运行

方式一（最简单）：直接双击 `index.html`，浏览器打开即可，无需任何环境。

方式二（推荐）：

```bash
python -m http.server 8765
# 浏览器访问 http://localhost:8765
```

无任何第三方依赖，无需构建，图片全程在浏览器本地处理，不会上传到任何服务器。

## 技术要点

- **CIELAB 最近邻匹配**：sRGB → 线性 RGB → XYZ(D65) → Lab，在 Lab 空间算
  欧氏距离选豆色。RGB 空间数值相近不等于视觉相近，Lab 是感知均匀空间，
  匹配结果明显更自然。
- **中位切分降色**：照片颜色先收敛到 K 个代表色再匹配豆色。直接逐像素匹配
  会让渐变区域被多个相近豆色拆碎，图纸杂乱且采购困难。
- **逐级降采样**：大图先逐半缩小到接近目标尺寸再最后一步插值，保留更多细节。
- **杂点清理**：若某豆与四邻全部不同色，按邻域主流色替换，减少"钉子豆"。

## 数据来源

Perler 色号与 HEX 对照取自 [Bitbead 色卡页](https://www.bitbead.app/en/colors/perler)，
共 117 色。色号为 Perler 实体豆官方编号，仅供学习与应聘笔试使用。
